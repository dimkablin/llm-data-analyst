# Синтетическое демо оттока операторов КЦ

Данные полностью синтетические. Они не относятся к реальным сотрудникам и не
подтверждают фактическое внедрение решения в Т2.

## Данные

`dataset.csv` содержит 3 600 уникальных операторов:

- 2 800 исторических наблюдений с известным `attrition_90d`;
- 800 текущих наблюдений с пустым целевым признаком;
- исторические увольнения покрывают не менее 24 месяцев.

Готового `risk_score` нет. Агрегированный прогноз увольнений должен приходить
через активную capability `forecast`, привязанную к Chronos MCP.

## Генерация

```powershell
python examples/hr_attrition_demo/generate_dataset.py
```

Генератор использует только стандартную библиотеку и фиксированный seed.

## Настройка прогноза

Подключите Chronos как MCP-сервер и привяжите его tool `forecast` к capability
`forecast`. Агент должен выбирать фактический bound tool из active capability
catalog, поэтому имя MCP-сервера не фиксируется в вопросах.

Загрузите `dataset.csv` или подключите таблицу
`demo_hr_attrition.operators`, выберите skill `hr_attrition_analysis` и
используйте вопросы из `prompts.md`. Дословный текст ведущего и подсказки для
показа находятся в `speaker_script.md`.
