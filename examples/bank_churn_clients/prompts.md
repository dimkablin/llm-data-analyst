# 🧠 Примеры запросов к LLM Data Analyst для Bank Churn Dataset

Эти промпты помогут продемонстрировать функциональность твоей системы при работе с датасетом оттока клиентов банка. Написаны простым, разговорным языком.

---

## 🔢 Общий анализ

1. Сколько клиентов в таблице?
2. Какие признаки есть в этом датасете?
3. Сколько клиентов ушло, а сколько осталось?
4. Какая доля клиентов относится к категории оттока?
5. Как распределены клиенты по семейному положению?

---

## 📊 Визуализации и графики

6. Построй гистограмму по возрасту клиентов.
7. Покажи круговую диаграмму по типам кредитных карт.
8. Нарисуй распределение клиентов по доходам.
9. Построй столбчатую диаграмму по количеству транзакций.
10. Построй тепловую карту корреляции между числовыми признаками.

---

## 📈 Продвинутый анализ

11. Есть ли связь между возрастом и оттоком?
12. У каких категорий дохода больше всего ушедших клиентов?
13. Как влияет кредитный лимит на вероятность оттока?
14. Какие типы карт чаще выбирают те, кто остался?
15. Построй график: отток по количеству транзакций.

---

## 🧪 Интересные идеи

16. Покажи топ-10 клиентов по лимиту кредитной карты.
17. Как распределяется активность клиентов по категориям карт?
18. Какие клиенты имеют наибольшее количество транзакций?
19. Как меняется доля оттока в зависимости от семейного положения?
20. Найди клиентов с высоким лимитом, которые всё равно ушли.
