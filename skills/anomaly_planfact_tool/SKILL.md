Используй этот инструмент, когда пользователю нужна **подготовка данных для поиска аномалий** или **подготовка данных для сравнения факта с планом / ожидаемым значением**.

### API
```python
# Доступен объект: anomaly_planfact
tool_result = anomaly_planfact.analyze_result("вопрос", artifact_name="anomaly_planfact_result")
tool_result = anomaly_planfact.analyze("вопрос")  # промежуточная проверка
```

### Final result protocol
Последняя строка — `tool_result`. Предпочитай `analyze_result()` для финального ответа.

## Когда использовать
Подходит для запросов вида:
- подготовить данные для поиска аномалий в выручке / заказах / трафике
- подготовить данные для анализа отклонений факта от плана
- подготовить данные для plan-fact анализа по периодам
- подготовить временной ряд для поиска аномальных периодов

## Что именно делать
Сформируй **один точный natural-language вопрос** для predict-service.

Вопрос должен описывать именно **подготовку данных для anomaly / plan-fact анализа**, а не формулировать задачу как готовый аналитический вывод.

В вопросе по возможности явно укажи:
- фактическую метрику
- плановую / ожидаемую / baseline-метрику, если она известна
- временное поле
- таблицу
- нужные фильтры
- сегмент / разрез, если анализ нужен по группам

Используй формулировки типа:
- `Подготовь данные для анализа аномалий ...`
- `Подготовь данные для план-факт анализа ...`
- `Подготовь временной ряд для поиска аномальных отклонений ...`

## Предпочтительный вызов
Для финального результата используй:

    tool_result = anomaly_planfact.analyze_result(
        "...",
        artifact_name="anomaly_planfact_result",
    )

Для промежуточной проверки можно использовать:

    tool_result = anomaly_planfact.analyze("...")

## Важные правила
- Не считай аномалии вручную через pandas.
- Не строй вручную plan-fact расчеты, если задачу можно решить этим инструментом.
- Не рисуй график вручную через plotly.
- Если не знаешь схему или названия полей — сначала вызови `database_tool`.
- Не придумывай названия таблиц и колонок.
- Не используй в natural-language вопросе формулировки вроде `найди аномалии`, `сделай plan-fact анализ`, `проведи анализ`, если можно явно сказать `подготовь данные`.
- Последняя строка кода должна быть ровно `tool_result`.

## Хорошие примеры

    tool_result = anomaly_planfact.analyze_result(
        "Подготовь данные для анализа аномалий факта выручки относительно плана по дням из таблицы sales по полю dt",
        artifact_name="anomaly_planfact_result",
    )

    tool_result = anomaly_planfact.analyze_result(
        "Подготовь данные для план-факт анализа по заказам по неделям из таблицы orders, сегмент country, фильтр channel = 'web'",
        artifact_name="anomaly_planfact_result",
    )

    tool_result = anomaly_planfact.analyze_result(
        "Подготовь временной ряд для поиска аномальных отклонений фактического числа регистраций от ожидаемого по месяцам из таблицы users по полю created_at",
        artifact_name="anomaly_planfact_result",
    )
