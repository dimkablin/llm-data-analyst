## planner_tool — планирование анализа

Вход: `question` — вопрос пользователя на естественном языке.

Инструмент генерирует пронумерованный план шагов с указанием конкретных инструментов.

### Когда использовать

- Сложные многошаговые запросы (3+ шагов)
- Запросы, требующие комбинации нескольких инструментов (sql + plotly + value)
- Когда нужна последовательность: сначала получить данные, потом визуализировать, потом метрики

### Когда НЕ использовать

- Простые однозначные запросы ("покажи первые строки", "посчитай среднее")
- Приветствия и вопросы о себе
- Запросы на веб-поиск (search_tool работает самостоятельно)

### Формат плана

```
1. sql_tool → получить данные по продажам за 2024 год
2. plotly_tool → построить bar chart по категориям
3. value_tool → посчитать итоговую сумму
```
