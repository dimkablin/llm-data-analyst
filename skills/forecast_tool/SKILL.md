Используй этот инструмент, когда пользователю нужна **подготовка данных для дальнейшего прогноза метрики во времени**.

### API
```python
# Доступен объект: forecast
tool_result = forecast.forecast_result("вопрос", artifact_name="forecast_result", horizon=12)
tool_result = forecast.forecast("вопрос", horizon=12)  # промежуточная проверка
```

### Final result protocol
Последняя строка — `tool_result`. Предпочитай `forecast_result()` для финального ответа.

## Когда использовать
Подходит для запросов вида:
- подготовить данные для прогноза выручки / заказов / пользователей / регистраций
- подготовить временной ряд по дням / неделям / месяцам для дальнейшего forecasting
- собрать данные для предсказания будущих значений метрики на несколько периодов вперед

## Что именно делать
Сформируй **один точный natural-language вопрос** для predict-service.

Вопрос должен описывать именно **подготовку данных для прогноза**, а не формулировать задачу как готовый аналитический результат.

В вопросе по возможности явно укажи:
- какую метрику нужно прогнозировать
- по какому временному полю строится ряд
- из какой таблицы брать данные
- какие нужны фильтры
- нужна ли разбивка по сегменту, если это важно

Используй формулировки типа:
- `Подготовь данные для прогноза ...`
- `Подготовь временной ряд для прогноза ...`
- `Подготовь данные для дальнейшего прогнозирования ...`

Если горизонт прогноза известен из запроса пользователя, передай его отдельным аргументом:

    tool_result = forecast.forecast_result(
        "Подготовь данные для прогноза выручки по дням из таблицы orders по полю order_date",
        artifact_name="forecast_result",
        horizon=30,
    )

## Предпочтительный вызов
Для финального результата используй:

    tool_result = forecast.forecast_result(
        "...",
        artifact_name="forecast_result",
        horizon=12,
    )

Для промежуточной проверки можно использовать:

    tool_result = forecast.forecast("...", horizon=12)

## Важные правила
- Не строй forecast вручную через pandas.
- Не рисуй прогноз вручную через plotly.
- Если не знаешь схему или названия полей — сначала вызови `database_tool`.
- Не придумывай названия таблиц и колонок.
- Не придумывай горизонт, если пользователь его не задавал.
- Не используй в natural-language вопросе формулировки вроде `построй прогноз`, `сделай прогноз`, `спрогнозируй`, если можно явно сказать `подготовь данные для прогноза`.
- Последняя строка кода должна быть ровно `tool_result`.

## Хорошие примеры

    tool_result = forecast.forecast_result(
        "Подготовь данные для прогноза количества заказов по неделям из таблицы sales по полю week_start",
        artifact_name="forecast_result",
        horizon=8,
    )

    tool_result = forecast.forecast_result(
        "Подготовь данные для прогноза числа новых пользователей по месяцам из таблицы users по полю created_at",
        artifact_name="forecast_result",
        horizon=6,
    )

    tool_result = forecast.forecast_result(
        "Подготовь временной ряд для прогноза выручки по дням из таблицы orders, фильтр country = 'RU'",
        artifact_name="forecast_result",
        horizon=30,
    )
