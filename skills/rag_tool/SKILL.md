## rag_tool — поиск по базе знаний

Вход: строка запроса на естественном языке.
Вызов: `rag_tool(query="запрос")` — без Python-кода, без sandbox.

### API
Вызывается с параметром `query` (не Python-sandbox): `rag_tool(query="запрос на ест. языке")`.

### Final result protocol
Не sandbox-инструмент. Вызывается напрямую — без Python-кода и без `tool_result`.

### Когда использовать

- Пользователь спрашивает о внутренних процессах, регламентах, политиках компании.
- Нужны доменные факты, задокументированные в корпоративной документации.
- Вопрос касается SLA, соглашений, описаний продуктов, организационных правил.

### Когда НЕ использовать

- Нужна **актуальная** информация из интернета → используй `search_tool`.
- Нужны вычисления или анализ данных → используй `sql_tool` / `pandas_tool`.
- Запрос — это общий вопрос, не требующий документации.

### rag_tool vs search_tool

| Критерий | rag_tool | search_tool |
|---|---|---|
| Источник | Внутренняя база знаний | Интернет |
| Тип данных | Регламенты, политики, доменные факты | Актуальные новости, внешние данные |
| Формат ввода | Строка-запрос | Python-код с `search.search()` |

### Правила

- Передавай чёткий запрос на естественном языке.
- Не оборачивай в Python-код — это не sandbox-инструмент.
- Если база знаний вернула пустой ответ, сообщи пользователю и предложи `search_tool` как альтернативу.
