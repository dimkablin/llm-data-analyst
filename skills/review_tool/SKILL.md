## review_tool — проверка качества ответа

Вход: `question`, `answer`, `tool_calls_count`, `artifact_count`.

Инструмент проверяет качество ответа и возвращает JSON с результатом: `{"pass": true/false, "issues": [...]}`.

### API
Вызывается с параметрами `question`, `answer`, `tool_calls_count`, `artifact_count` (не Python-sandbox).

### Final result protocol
Не sandbox-инструмент. Возвращает JSON — без Python-кода и без `tool_result`.

### Когда использовать

- После завершения сложного анализа (3+ tool calls), перед финализацией ответа
- Когда не уверен в качестве ответа
- Когда запрос пользователя конкретный и требует точного ответа

### Когда НЕ использовать

- Для простых запросов (1-2 tool calls)
- Для приветствий и простого чата
- Если ответ очевидно полный и корректный

### Что проверяется

1. Ответ не пустой
2. Ответ не слишком короткий (при отсутствии артефактов)
3. Если просили визуализацию — есть ли график
4. Для сложных запросов (>2 tool calls) — LLM-оценка полноты и корректности
