## value_tool — скалярные метрики

Вход: Python-код. Выполняется в **sandbox сессии** — все переменные сохраняются между вызовами.

### API
```python
# Нет фиксированного API — свободный Python-код в sandbox
# Доступно всегда: df, pd, np
# При подключённой БД: db.query_dataframe(sql: str) -> pd.DataFrame
```

### Scope
- `df` — DataFrame текущей сессии (уже загружен, **не вызывай** `pd.read_csv`)
- `pd`, `np` — всегда доступны
- `db` — при подключённой БД
- Все переменные из предыдущих tool-вызовов доступны по имени

### Final result protocol
Последнее выражение в коде должно быть `tool_result`. Sandbox захватывает только последнее выражение.

Для скалярных значений `tool_result` содержит `artifact_type: "value"` и `items` со скалярами.
Структуру и примеры смотри в DETAILS.md — вызови `get_tool_instructions('value_tool', details=True)`.

### Rules
- Только для коротких скалярных значений (не длинные тексты)
- Последняя строка: `tool_result`
- Округляй float до 2-4 знаков
- НЕ вызывай `pd.read_csv()`
- Можешь использовать переменные из предыдущих tool-вызовов
- Запрещено: `os`, `sys`, `globals()`
