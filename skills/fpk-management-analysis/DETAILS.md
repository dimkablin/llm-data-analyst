# Справочник источника `demo_fpk`

Это описание схемы и доменных ограничений, а не готовый план запроса. Перед
расчётом сверять названия и типы колонок с фактическим catalog context.

## `stat_stats`

Дневные показатели пассажирских перевозок в разрезе ФПК/филиала и сценария.

- Ключевые измерения: `date`, `structure`, `sys_section`, `metric`.
- Сценарии: `metric='fact'` и `metric='plan'`.
- Меры: `pass_count`, `pass_turnover`, `car_turnover`, `seat_turnover`.
- Исключать строки с `COALESCE(is_deleted, false)=true`.
- Для месячного результата сначала агрегировать дневные строки через
  `date_trunc('month', date)`.
- `seat_turnover` допустим как филиальный прокси операционной загрузки, но это не
  коэффициент занятости мест. Не переименовывать его в `cap_usage`.

## `stat_csi`

Помесячные показатели качества по ФПК и филиалам.

- Ключевые измерения: `date`, `structure`, `type`, `sys_section`, `add_time`.
- `type` разделяет `fact`, `plan` и `delta`; для фактической динамики выбирать
  только `fact`.
- В таблице есть компоненты качества, индекс удовлетворённости пассажиров
  `индекс_удовлетворенности_пас` и индекс потребительской лояльности
  `индекс_потребительской_лояльност`. Не считать их взаимозаменяемыми без
  определения из семантического слоя.
- При нескольких версиях одной комбинации `date`, `structure`, `type`,
  `sys_section` выбирать запись с максимальным `add_time`.

## `stat_isoo`

Обращения пассажиров в длинном разрезе тематик и широких колонках филиалов и
каналов.

- Ключевые измерения: `date`, `sys_section`, `шифр`, `тематика_обращения`.
- Для негативных обращений использовать только `шифр LIKE 'NEG_%'`; не
  примешивать итоги и другие типы сообщений.
- `всего_по_филиалам`, колонки отдельных филиалов и колонки каналов описывают
  разные представления одного потока. Их нельзя складывать между собой.
- Выбирать ровно одно временное зерно `sys_section`; не суммировать дневные и
  месячные строки вместе.

## `stat_manual`

Длинная таблица KPI уровня ФПК.

- Ключевые поля: `value_name`, `value`, `date`, `sys_section`, `metric`.
- `metric` разделяет `plan`, `fact` и сохранённый внутренний `forecast`.
- Значение `sys_section='quater'` написано именно так в контракте источника.
- `cap_usage` доступен на уровне ФПК. Агрегированные проценты загрузки считать
  как отношение сумм совместимых числителя и знаменателя, а не как среднее
  процентов.
- Масштаб `car_turnover` отличается от одноимённой меры в `stat_stats`; сравнение
  допустимо только после явной проверки и приведения единиц.

## Сопоставление филиалов

| CSI (`stat_csi.structure`) | Stats (`stat_stats.structure`) | ISOO column |
|---|---|---|
| `С-ЗАП` | `СЕВ.ЗАП.` | `с_зап` |
| `МОСК` | `МОСК.` | `моск` |
| `ГОРЬК` | `ГОРЬК.` | `горьк` |
| `С-КАВ` | `С-КАВ.` | `с_кав` |
| `ПРИВ` | `ПРИВ.` | `прив` |
| `КБШ` | `КУЙБ.` | `кбш` |
| `УР` | `СВЕРД.` | `ур` |
| `З-СИБ` | `З-СИБ.` | `з_сиб` |
| `В-СИБ` | `В-СИБ.` | `в_сиб` |
| `ДВОСТ` | `ДВОСТ.` | `двост` |

Материализовать и проверить это сопоставление перед межтабличным join. Дата без
филиала не является достаточным ключом соединения.

## Общие правила расчёта

- Период брать из запроса. Если он не задан и влияет на смысл результата,
  уточнить его либо явно назвать выбранный полный период по доступным данным.
- Для упоминания «лета» использовать июнь–август внутри выбранного года;
  сравнительные окна согласовывать с запросом, а не фиксировать заранее.
- Процентные отклонения считать с защитой знаменателя через `NULLIF` и отдельно
  обозначать проценты и процентные пункты.
- Для рейтинга филиалов исключать строку `ФПК`; для итогового показателя ФПК не
  суммировать её повторно с филиалами.
- Формулы именованных бизнес-метрик в этом справочнике не определяются: их
  источником является семантический каталог или явная формула пользователя.
- Корреляции и сезонные совпадения не доказывают причинность; показывать
  исключения и возможные смешивающие факторы.
